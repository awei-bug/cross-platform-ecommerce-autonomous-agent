# 当前业务价值核查（2026-10-15）

后续进展（同日）：已实际用浏览器采集 Amazon 美国站家居热销榜及3个商品页，保存截图、规格、币种、来源和时间，写入日常库，并接入按批次/国家/币种隔离的成本空间分析。无需店铺授权。见 [浏览器采集说明](BROWSER_RESEARCH.md) 与 [首批结果](research/2026-10-15-US-HOT-PRODUCTS.md)。以下保留实施前的源码核查；其中“尚无浏览器采集、调研未按批次筛选”已得到局部补齐，趋势预测、真实采购报价和盈利验证仍缺失。

## 结论

当前可作为局部运营辅助工具，尚不能当作已经验证业务成效的全自动跨境运营系统。界面、状态流转和自动化测试证明软件行为；节省多少时间、选品是否准确、是否提高利润，尚无真实经营样本验证。

本次为源码与既有文档核查，未调用付费模型、外部平台或日常业务数据库，未重新做真实授权联调。本次不删除功能、不修改产品代码。

## 能解决的具体问题与边界

| 具体问题 | 当前能力 | 前提与限制 |
| --- | --- | --- |
| 候选商品卖多少才不亏、采购多少占用多少资金 | 实际计算 landed cost、保本售价、单位利润、毛利和采购金额 | 采购、运费、税费、损耗、佣金、广告和汇率来自用户报价；不自动验证报价，不等于完整会计利润或销量预测 |
| 商品文案和短视频脚本重复撰写 | 已有真实模型适配和候选版本管理，支持人工确认 | 需要有效模型配置和真实生成开关；跨境默认 Listing 是模板，不能把“待核对”五点当作成稿 |
| 素材文件散乱、版本难追溯 | 实际上传、预览、版本确认、尺寸/词规则检查 | 不自动证明版权或完整平台合规；图片生成另需适配的模型能力 |
| 搜集与整理竞品 | 支持人工整理和有权限时的淘宝客导入 | 淘宝客数据是淘宝/天猫口径，不等于 Amazon 等跨境市场需求；导入数据不含自动获取的差评痛点 |
| 内容稿件与发布状态管理 | 可保存草稿，存在抖音内容投稿真实调用路径 | 必须申请应用能力、配置凭证、授权账号并提供视频；本项目未完成当前用户账号的真实发布验收 |
| 超预算/超额退款/备货审核需留痕 | 实际阈值判定、暂停、人工审核、版本校验与审计 | 无真实业务接入时主要体现工程基础价值，不直接产生用户当前的经营收益 |

## 已确认的业务缺口

1. **选品评分缺少客观证据。** `backend/app/schemas/ecomops.py` 的市场、竞争、供应与合规评分默认70；`ecomops_specialists.evaluate` 将它们与利润评分等权平均。分数可计算，但不能据此声称市场已验证。
2. **调研未形成市场情报能力。** `ecomops_specialists.market` 读取组织内已导入的竞品记录，直接附带输入市场分；未自动采集实时搜索、趋势、社媒或跨境销量。当前还没有按候选品类筛选该步骤的竞品记录。
3. **营销建议仍有模板性。** `marketing_plan` 的站内、活动、站外预算分别固定为70%、20%、10%；没有基于真实渠道效果优化该分配。
4. **关键数据与产出尚未贯通。** 淘宝客导入写 `CompetitorModel`，跨境调研读 `OpsRecord(kind=competitor)`；当前导入路径未同步到跨境数据中台。跨境 Listing/模型稿保存在任务输出，未自动作为素材版本或内容发布草稿保存。这些功能分别可用，用户仍须转录或复制。
5. **跨境执行未接入。** 五个平台的目录不是官方连接器；上架、广告、退款、仓储与物流不能据当前任务完成状态推断已执行。现有国内抖店连接实现也不等于用户已具备授权资格。
6. **合规无法自动给出完整结论。** 当前为配置词规则与阈值。专利、商标、法规、认证、税务与清关仍需外部证据及人工核验。

## 对当前用户的优先级判断

用户没有自有店铺；此前要求撤销功能裁剪，此决策继续保留。依据当前条件，优先完成无需店铺即可验证的商品研究与内容准备业务，保留其他模块作未来扩展。

建议下一条实际验收链路：真实候选商品与供应商报价 → 可追溯竞品资料 → 成本/利润测算 → 展示缺失信息与假设 → 人工决定保留/淘汰 → 生成并保存可复用文案。淘宝客仅作为其适用范围内的数据来源，跨境需求必须使用目标市场的资料。

验收不以“所有 Agent 执行成功”为标准，而检查：

- 每个价格、费率、竞品与关键判断是否有来源、时间和适用市场；缺失项是否明确显示。
- 相同真实输入是否能得到可复算的结果，成本字段是否足够支持这次决策。
- 用户能否完成候选比较和淘汰，输出能否直接进入素材库，避免二次抄录。
- 与人工完成同一批商品研究相比，实际节省的时间、需要纠正的结论数量，以及文案可采用比例；当前尚未测量，不能提前给出效果数字。

以上为下一阶段建议，尚未据此修改评分逻辑或数据接入。
